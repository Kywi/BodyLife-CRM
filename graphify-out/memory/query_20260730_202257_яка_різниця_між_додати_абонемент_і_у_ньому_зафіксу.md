# Q: Яка різниця між додати абонемент і у ньому зафіксувати оплату та додати платіж і підв'язати абонемент я шось не розумію

## Answer

Expanded from original query via graph vocab: [membership, issue, issued, payment, record, linked, price, cash, абонемент, оплата]. Issue Membership with payment creates a new issued membership and an attached membership-sale cash Payment in one transaction. Create Payment makes only a Payment; linking an existing Membership is optional attribution and does not create, activate, extend, or recalculate that Membership. Use the combined flow for a new membership paid at issuance; use standalone Payment for money recorded later, partial/additional payments, one-off/trial/other contexts, or payments without a membership. Do not enter the same cash receipt through both flows because that duplicates the payment.
