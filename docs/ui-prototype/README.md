# BodyLife UI template lab

This directory is a static, review-only GitHub Pages artifact for exploring
BodyLife CRM presentation templates at tablet and phone sizes.

It uses deterministic fixture content and has no authentication, backend,
database, commands, canonical reads, or persistence. It is not the CRM
application, a production hosting option, a Wave 1 visual-fidelity candidate,
or acceptance evidence. Approval of this template lab does not change the
status of any migration wave. Formal visual approval must still use the real
authenticated Razor Pages candidate with canonical data and the acceptance
gates in `docs/ui-visual-fidelity-migration-plan.md`.

The Pages workflow publishes only this directory. Never place secrets,
production exports, real client data, session identifiers, or private
operational information here.
