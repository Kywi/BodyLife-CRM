Вид типу незмінний

Під час створення: Owner явно обирає звичайний (ordinary) або разовий (one_off) вид. Обидва мають додатну ціну; для разового типу ліміт завжди дорівнює 1.

Під час редагування: вид доступний лише для читання. Щоб змінити його, Owner деактивує старий тип і створює новий; умови вже виданих абонементів не змінюються.

Позитивна ціна обов’язкова; нульова ціна або нульовий ліміт не приймаються.

Додати тип абонемента

Створення доступне лише Owner; це статичний review-only preview.

Звичайний і разовий типи мають додатну ціну; для разового типу ліміт завжди дорівнює 1. Надсилання тут не створює запис і не оновлює стан із сервера.

Перевірте поля:
  • назва й вид обов’язкові;
  • тривалість і ліміт мають бути не менше 1;
  • для разового типу ліміт має дорівнювати 1;
  • ціна має бути більшою за нуль;
  • валюта обов’язкова, до 12 символів.
